The application

A coding agent that keeps the work.

std::slop is a persistent, SQLite-driven C++ CLI coding agent. It makes repository work explicit: inspect, edit, validate, and review.

First run

Build it, configure it, start a session.

The recommended onboarding path builds the binary with Bazel, chooses API-key or OpenAI OAuth authentication, and starts either an interactive or batch session.

terminal
$ bazel build //:std_slop
$ std_slop --prompt \
    "Summarize the repository structure"
$ std_slop

Core model

State is part of the workflow.

Ledger

SQLite persistence

Messages, tool calls, sessions, skills, scratchpads, project context, usage, and mail metadata are stored in a database.

Sessions

Isolated histories

Each session has its own conversation history and context settings while global tools and skills remain available.

Context

Accordion history

Retain a cache-friendly prompt prefix, reset at a watermark, and preserve the complete recent interaction groups.

Capabilities

Make the agent fit the repository.

01

Direct tools

Read files, search the tree, apply exact edits, run shell validation, query SQLite, manage scratchpad state, and operate the Git mail workflow.

02

Skills and personas

Load project instructions from AGENTS.md and activate modular SKILL.md instructions when a task needs them.

03

Batch and structured output

Use --prompt, --prompt_file, --output=json, or JSON Schema-constrained output for scripts and automation.

04

Mail Mode

Develop on staging branches, produce atomic patches, verify each commit, review the series, and finalize only after explicit approval.

Mail Mode

Make the change reviewable.

Mail Mode uses staging branches, atomic patches, verification, review, and explicit finalization to keep agent-assisted changes inspectable.
