Model Context Protocol

Connect tools without hiding the boundary.

std::slop includes a reusable C++ MCP client library and runtime integration for discovering and calling tools from Streamable HTTP MCP servers.

Runtime flow

From server configuration to agent tool.

mcp.iniconfigured servers
→
tools/listdiscovery
→
mcp_server_toolnormal catalog
→
std::sloptool call

At startup, enabled servers are started, their tools are discovered, and discovered tools are projected into the normal std::slop tool catalog.

CLI workflow

Configure MCP from std::slop.

Use the command-line workflow to add servers, list registrations, authenticate, refresh OAuth tokens, log out, or remove a server.

std_slop mcp add github \
  --url https://example.com/mcp \
  --auth bearer \
  --token YOUR_TOKEN

std_slop mcp list
std_slop mcp oauth-login github

C++ library

Use the client directly.

Streamable HTTP

A small, typed transport layer.

The client sends JSON-RPC messages to one MCP endpoint. Responses may be direct JSON or server-sent events. Session identifiers, protocol versions, bearer tokens, and caller-supplied headers are handled by the transport.
