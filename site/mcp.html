Library / MCP

A self-contained C++ MCP library inside std::slop.

The mcp/ package has a clean typed API for Streamable HTTP MCP servers. The agent runtime uses the same library for server startup, discovery, authentication, and tool dispatch; the package is not a separate product boundary.

C++ API

Connect, inspect, and call through typed methods.

client.cpp
#include "mcp/client.h"
#include "mcp/session.h"

slop::mcp::StreamableHttpConfig config;
config.endpoint_url = "https://example.com/mcp";

slop::mcp::InitializeOptions options;
options.client_info.name = "my-client";
options.client_info.version = "1.0";

auto session = slop::mcp::ConnectStreamableHttp(
    config, options, &http_client);
if (!session.ok()) return session.status();

RETURN_IF_ERROR((*session)->Ping());
auto tools = (*session)->ListTools();
auto result = (*session)->CallTool(
    "search", nlohmann::json{{"query", "mcp"}});

Sessions expose methods for ping, tool/resource/prompt discovery, calls, notifications, and close.

Transport

Streamable HTTP and JSON-RPC.

The transport sends JSON-RPC requests to one endpoint. Responses can be direct JSON or text/event-stream. It manages protocol headers, session identifiers, bearer authorization, and caller-supplied headers.

TransportStreamable HTTP
ProtocolJSON-RPC
DiscoveryTools, resources, prompts
AuthBearer and OAuth PKCE

Runtime integration

Discovery projects into the agent catalog.

At startup, std::slop reads the MCP registry, starts enabled servers, sends tools/list, and registers discovered tools as mcp_<server>_<tool>. Calls route back through the matching MCP session.

Authentication

Bearer tokens and OAuth discovery.

Static bearer tokens are kept out of mcp.ini and loaded from the token store. OAuth support includes protected-resource discovery, authorization-code + PKCE login, refresh, and client-secret handling at request time.

mcp command line
std_slop mcp add github \
  --url https://example.com/mcp \
  --auth bearer \
  --token YOUR_TOKEN

std_slop mcp oauth-login github
std_slop mcp oauth-refresh github
