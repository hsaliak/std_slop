Library / Markdown

A self-contained C++ Markdown parser and renderer.

The markdown/ package is used by the std::slop terminal UI, but has a clean API and package boundary of its own. It parses with Tree-sitter and renders ANSI-styled terminal output.

C++ API

Parse a source buffer and render into a sink.

markdown.cpp
#include "markdown/parser.h"
#include "markdown/renderer.h"

slop::markdown::MarkdownParser parser;
std::string source = "# Hello World\\nThis is **bold**.";
auto parsed = parser.Parse(std::move(source));
if (!parsed.ok()) return parsed.status();

slop::markdown::MarkdownRenderer renderer;
renderer.SetMaxWidth(80);
std::string output;
renderer.Render(*parsed.value(), &output);
std::cout << output;

Parser

Tree-sitter structure.

The parser wraps the block-level and inline Markdown grammars. Fenced code blocks are parsed through language injections and stored with their source ranges and syntax trees.

//markdown:parser

Renderer

ANSI terminal output.

The renderer traverses the parsed tree, applies centralized styles, and supports sink-based output so callers can reuse and reserve their destination buffer.

//markdown:renderer

Implementation details

Output constraints are handled in the library.

01

Fenced-code highlighting

C/C++, Python, Go, JavaScript, Rust, and Bash/Shell are supported through Tree-sitter grammars.

02

Table layout

Wide tables shrink the widest columns, wrap multi-line cells, and preserve the table grid within max_width.

03

Buffer ownership

MarkdownParser::Parse takes the source by value so the parsed result owns the buffer referenced by Tree-sitter.

04

UTF-8-aware width

Width calculation and word breaking account for multi-byte text and ANSI-styled content.

Bazel targets

Use the package through its public targets.

The package is part of the same repository and build graph as the agent. Its tests cover parser structure, rendering, syntax highlighting, and terminal layout.

bazel
bazel test //markdown:parser_test
bazel test //markdown:renderer_test
