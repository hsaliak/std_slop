The terminal renderer

Markdown that belongs in the terminal.

The standalone C++ Markdown library parses documents with Tree-sitter and renders structured, ANSI-styled output for the std::slop interface.

Parser

Keep the structure.

The parser wraps the block and inline Tree-sitter Markdown grammars. It handles injected fenced-code trees and keeps the source buffer owned by the parsed result.

//markdown:parser

Renderer

Make it readable.

The renderer walks the parsed tree, applies centralized ANSI styles, and writes terminal-ready output through a sink-based API.

//markdown:renderer

Example

Parse once, render where it matters.

The library takes ownership of the source buffer so Tree-sitter pointers remain stable. The renderer can write into a reusable output string.

example.cpp
slop::markdown::MarkdownParser parser;
auto result = parser.Parse(std::move(source));

slop::markdown::MarkdownRenderer renderer;
renderer.SetMaxWidth(80);
renderer.Render(*result.value(), &output);

Built for terminal output

Details that make a long response usable.

01

Syntax highlighting

Fenced code blocks support C/C++, Python, Go, JavaScript, Rust, and Bash/Shell through Tree-sitter grammars.

02

Dynamic table wrapping

Wide tables shrink their widest columns, wrap multi-line cells, and preserve the table grid within a configured maximum width.

03

UTF-8 awareness

Width calculations and word breaking account for multi-byte content and styled output.

04

Centralized themes

Markdown colors and element styling live in the ANSI theme so the terminal look can be adjusted in one place.
