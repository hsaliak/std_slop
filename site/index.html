std::slop: a persistent C++ coding agent.

A command-line agent for repository inspection, exact edits, validation, and review. The repository also contains self-contained C++ libraries for MCP Streamable HTTP and terminal Markdown rendering.

Agent runtime · MCP library · Markdown library

Repository components

One codebase with a narrow runtime boundary.

Agent

Persistent execution

The CLI uses a SQLite ledger for messages, tool calls, sessions, skills, scratchpads, project context, and usage. The orchestrator assembles provider requests from session state.

Library / MCP

The mcp/ package is a self-contained C++ library for Streamable HTTP, JSON-RPC, session lifecycle, discovery, and authentication. The runtime uses it to register server tools.

Change model

Manual review is part of the design.

std::slop prioritizes explicit tool boundaries, manual code review, and clean, bisect-safe changesets over opaque autonomous changes. Mail Mode keeps the agent on a staging branch until the patch series has been verified and approved.

01

Inspect

Read the repository, search files, inspect the database, and establish the task state before editing.

02

Change

Use exact edits and keep each logical change isolated in the working tree.

03

Validate

Run deterministic tests and checks through explicit tools and record the result.

04

Review

Review the diff and patch series, then finalize only the approved HEAD.
