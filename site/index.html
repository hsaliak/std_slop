Designed for explicit work

Inspect, change, validate, review.

Direct tools make ordinary operations visible. Mail Mode turns a change into a reviewable staging-branch patch series. The result is an agent workflow that stays close to the repository.

01Inspect

Read files, search the tree, query the ledger, and understand the project.

02Edit

Apply focused exact-text changes with a clear working-tree diff.

03Validate

Run tests and checks through explicit shell commands.

04Review

Commit atomic patches and finalize only after approval.
